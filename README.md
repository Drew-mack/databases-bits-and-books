# Bits & Books database project

This repository contains the bookstore database course project and its earlier checkpoint materials.

**Current Checkpoint 04 work:** see [checkpoint_04/README.md](checkpoint_04/README.md). It contains the corrected schema, populated database, fourteen queries, query results, manual, and the scripts and documentation used to rebuild and check them. The submission archive is `Checkpoint_04.zip`.

**Earlier work:** `checkpoint_03/` and `Checkpoint_03.zip` preserve the previous submission; `checkpoint2.zip`, `ERD/`, the root-level schema, query, database, manual and CSV files are earlier project snapshots or group contributions. In particular, the root `bits_and_books.db` is empty and the root `queries.sql` is an earlier version; use the Checkpoint 04 folder for the current work. `Query_Results/`
